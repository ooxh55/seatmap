표시할 좌석배치도가 없어요

2D 좌석배치도의 저장·공유 → 복사 내용을 붙여넣거나, 저장해 둔 data.json / 좌석배치도 HTML·TXT 파일을 불러오세요. 관리자 모드에서 직접 그려도 됩니다.

? 조작법

설정

권한은 3단계예요. 사용자는 보기만, 관리자는 도면·데이터 전체 편집, 수정은 사람 이름 추가/삭제만 가능합니다. PIN을 정하면 해당 버튼을 누를 때 입력해야 들어갑니다. PIN은 간단한 잠금이라 강력한 보안은 아니에요.

GitHub 게시 (사이트에 바로 저장)

2D 앱과 같은 data.json을 씁니다. 여기서 게시해도 2D 화면에 그대로 반영돼요.

콘텐츠 쓰기 권한만 가진 Fine-grained PAT를 권장해요. 토큰은 게시 파일에 포함되지 않습니다.

구글 시트 인원 정보 자동 연동 (하루 1회)

시트의 이름·실·팀·파트·담당업무·슬랙ID를 하루 한 번 받아, 이름이 같은 좌석의 정보를 갱신해요. 좌석 위치·새 사람 배치는 바꾸지 않아요.

시트는 링크가 있는 모든 사용자(뷰어)로 공유하거나 파일 → 공유 → 웹에 게시(CSV)로 열어 두어야 브라우저가 읽을 수 있어요. 첫 줄은 머리글(이름, 실, 팀, 파트, 담당업무, 슬랙ID)이고 열 순서는 달라도 돼요. 링크를 아는 사람은 시트 내용을 볼 수 있으니, 필요한 열만 담은 연동 전용 시트를 쓰세요.

실시간 접속자 (걷는 사람 표시)

배포 후 동시 접속자 수만큼 해당 층에 사람이 걸어 다녀요. 무료 Supabase 프로젝트의 URL과 anon(public) 키를 넣으면 모든 방문자끼리 연결됩니다. 비워두면 같은 PC의 브라우저 탭끼리만 연결돼요.

데이터 관리

이름이 있는 좌석의 부서(실/팀/파트)·담당업무·슬랙 ID를 한 곳에서 관리해요. 표에서 바로 고치거나, 엑셀 업로드 또는 CSV로 한꺼번에 올릴 수 있어요. (이름이 같으면 갱신, 없으면 새 좌석으로 추가)

엑셀로 추가/수정 엑셀 모듈을 못 불러왔어요(인터넷 필요). CSV 붙여넣기를 이용하세요.

저장 · 공유

사이트에서 관리하려면 이 버튼만 쓰면 돼요. 현재 배치를 저장소 데이터 파일(data.json)로 올려 모든 방문자(2D·3D)에게 반영합니다.

그 밖의 방법 — 데이터를 복사해 백업하거나, 다른 데이터를 붙여넣어 불러오기. 데이터를 담은 3D HTML 파일을 받을 수도 있어요.

부서별 인원

이름이 등록된 좌석을 기준으로 집계해요. 항목을 누르면 해당 층으로 이동해 인원을 강조합니다.
